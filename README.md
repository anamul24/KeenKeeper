# KeenKeeper

**Personal Relationship Management**

A beautiful and intuitive web application to help you nurture and maintain meaningful relationships

## About the Project 

KeenKeeper helps you never lose touch with the important people in your life. It tracks your last interaction, reminds you when to reach out, logs every call/text/video, and gives you visual analytics of your relationship health.

## Technologies Used
- **React 19** + **Vite** (Fast development buid tool)
- **React Router DOM v7** - Client-side routing
- **Tailwind CSS v4** - Utility-Fist style
- **Lucid React** - Beautiful & consistent icons
- **Recharts** - Interactive pie Chart for analytics
- **React Toastify** - Elegant Toast notifications
- **localStorage** - Data persistance
  
## Key Features
- **Dashboard** - Overview with summary cards and all your friends
- **Friend Profiles** - Detailed view with bio, tags, and relationship goal
- **Quick Check-In** - One-click logging of call, text, or Video interactions
- **Timeline** - Complete history of all your interactions with the filter option
- **Analytics** - Beautiful Pie Chart showing your interaction patterns
- **Fully Responsive** - Works perfectly on Mobile, tablet & Desktop
- **Toast Notifications** - Real-time feedback on actions
- **Persistent Storage** - Data saved using localStorage
